- `objects/`: object events and resource definitions.

## Using this source

This is a code reference snapshot. It is not a complete GameMaker project and cannot be built on its own. Project registrations, sprites, sounds, fonts, included files, and extensions are not included. Supply dependencies and replacement content under suitable terms before building a working project.

The source comes from the published development branch or tag. Uncommitted local changes are not included. Source history, internal documentation, signing keys, and bundled dependency binaries are not copied. Future snapshots use the same inclusion policy.

Excluding content from public source does not establish rights to distribute it in game builds.
